Uwazi & Utegemea kwa umma

  • /ledger — Public Spending Ledger (invoices zilizolipwa)
  • /reports — Public impact stories
  • Complaints — safeguarding / financial
  • Track — mwombaji wa mgeni /track/:token

Staff — Admin vs Manager

  • Manager: requests, items, invoices, equipment, reports, suppliers
  • Admin: yote ya manager + users, donations, payments, ledger, audit-logs, exports
  • Kila action ya staff imerekodiwa kwenye AuditLog

Pesa — Rule ya Mwisho

  • Donor → Payment provider → OWERU → Supplier
  • Hakuna njia inayolipa mwombaji/recipient
  • Donations: item-level, all-or-nothing, dirisha la siku 60
